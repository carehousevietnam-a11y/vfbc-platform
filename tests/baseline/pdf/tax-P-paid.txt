EXECUTIVE SUMMARY
결론 · 근거 · 영향 · 권고
결론 · 선택하신 사건유형은 내 소득에 대한 세금입니다. 1차·2차 답변을 기준으로 정리한 결과이며, 자료 내용 검토는 전문가 확인 단계에서
진행됩니다.
EVIDENCE & KEY FINDINGS
확인 완료 요건과 추가 확인 항목
■ 1차 확인 사항
✓ 베트남 회사에서 받은 급여와 관련된 세금을 확인하고 싶습니다.
✓ 급여에서 세금이 어떻게 처리되었는지 확인합니다.
✓ 받을 때 상대방이 먼저 세금을 떼고 지급한 상태입니다.
✓ 자료가 대부분 있어 계산 과정부터 확인할 수 있습니다.
■ 2차 확인
✓ 안내 출처 · 세무기관에서 직접 받은 안내이고 발신 경로도 확인하셨습니다.
✓ 안내와 실제의 차이 · 안내에는 세금이 처리됐다고 되어 있지만, 실제로 받은 돈에서 어떻게
처리됐는지는 확인되지 않습니다.
✓ 금액과 계산 기준 · 급여에서 빠진 세금 금액을 확인 중이며, 급여나 지급액이 계산 기준이라고
들으셨습니다.
✓ 기한 · 공식 안내에서 확인한 기한이 이미 지났거나 곧 다가와, 가장 먼저 확인해야 합니다.
✓ 조치 이후 · 문의 후 처리 방법은 안내받았지만, 어떤 자료를 내야 하는지는 아직 분명하지
않습니다.
✓ 막힌 이유와 가진 자료 · 서류의 내용을 이해하지 못해 막혀 있고, 해당 서류는 가지고 계십니다.
✓ 알고 싶은 것과 도움 범위 · 받은 안내가 맞는지 확인하고, 맞다면 신고·납부 방법까지 알기를
원하십니다.
