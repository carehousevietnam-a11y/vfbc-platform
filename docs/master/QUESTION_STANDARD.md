# 질문·선택지 기준

- 질문 1개는 한 문장 안에 두 가지를 묻는다(쉼표로 이어진 복합 질문). 예: "상대나 회사의 이름은 어디까지 확인되었고, 그 정보가 실제로 연락한 사람과 이어지는지도 확인하셨나요?"
- 선택지 1개는 "**굵은 요점**" + 설명 문장으로 쓴다. 굵은 요점이 첫 번째 정보, 설명 문장이 두 번째 정보다.
- 한 선택이 저장하는 필드는 정확히 2개이며, 첫째는 질문 앞부분, 둘째는 뒷부분과 대응한다.
- 선택지는 4~5개 + "직접 입력"(직접 입력은 5개에 포함하지 않으며 5개를 넘기지 않는다). 값 코드는 영문, 고객 문구는 한글. 같은 값은 같은 라벨(G 라벨표).
- 선택지 한 줄은 굵은 요점 포함 45자 이상, 마침표 1개 이상. 단정 금지어와 영문 노출은 금지.
- 2차 단계 비중 60% 이상(30:70 허용).
- 기준 견본: docs/master/content/TAX_CONTENT_FINAL.md 와 FRAUD_CONTENT_V3.md 의 B 경로 Q5.
- 이 문서는 확정 기준이다. 사용자에게 다시 설명을 요구하지 말고, 모든 콘텐츠 작업 전에 읽는다.
