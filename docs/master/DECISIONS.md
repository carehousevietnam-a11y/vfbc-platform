# 대표 결정 장부 (DECISIONS)

오래 가는 규칙은 대표 승인 후 STANDARDS.md로 올린다(올린 항목은 번호를 적는다). 이 문서는 잠금 대상이 아니라 바로 추가할 수 있다.
