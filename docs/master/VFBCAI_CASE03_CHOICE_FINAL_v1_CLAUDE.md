## A. 1차 공통

### case03_authorityDemand
Q: 교통국에서 받은 방문·설명 안내는 어떤 상황인가요?
- specific_incident: 특정 위반이나 사고에 대해, 직접 와서 설명하라는 안내를 받았습니다. [대상: 특정 사건 / 요구: 방문 설명]
- submission_review: 제출한 서류나 신청 내용 때문에, 방문해서 확인받으라는 안내를 받았습니다. [대상: 제출 서류 / 요구: 방문 확인]
- repeat_demand: 이미 한 차례 방문하거나 설명했는데, 다시 오라는 안내를 받았습니다. [대응 1회 이상 / 재요구]
- reason_unclear: 방문하거나 설명하라는 안내는 받았지만, 그 이유는 설명받지 못했습니다. [요구 받음 / 이유 모름]
- prep_unclear: 방문해야 하는 이유는 알지만, 무엇을 준비해서 가야 하는지 모릅니다. [이유 앎 / 준비물 모름]

### case03_inquiryFocus
Q: 교통국은 이번 방문이나 설명으로 무엇을 확인하려는 것 같나요?
- action_facts: 제가 운전하거나 행동한 일에 대해, 당시 상황을 직접 듣고 싶어 하는 것 같습니다. [대상: 본인 행동 / 방식: 진술]
- specific_event: 특정 날짜의 위반이나 사고에 대해, 기록된 내용이 맞는지 확인하려는 것 같습니다. [대상: 특정 사건 / 방식: 기록 대조]
- submitted_docs: 제가 제출한 서류나 신청 내용에 대해, 확인할 부분이 있다고 했습니다. [대상: 제출 서류]
- unclear: 안내는 받았지만, 무엇을 확인하려는 것인지는 적혀 있지 않았습니다. [안내 받음 / 목적 미기재]
- unsure: 목적이 적혀 있는 것 같지만, 베트남어나 행정 용어 때문에 이해하지 못했습니다. [기재 있음 / 이해 못함 / 원인: 언어]

### case03_customerResponse
Q: 안내를 받은 뒤, 현재 어디까지 진행하셨나요?
- none: 안내만 받았고, 아직 교통국에 연락하거나 방문하지 않았습니다. [연락 X / 방문 X]
- phone_message: 교통국에 전화나 메시지로 문의했지만, 아직 직접 방문하지는 않았습니다. [문의 함 / 방문 X]
- attendance: 교통국에 직접 방문해 상황을 설명했습니다. [방문 함 / 구두 설명]
- explanation_with_docs: 방문하거나 설명하면서, 관련 서류나 자료도 함께 제출했습니다. [설명 함 / 서류 제출 함]
- other_method: 대행사나 회사 담당자, 지인에게 맡겨 그쪽에서 진행하고 있습니다. [대리 진행 / 본인 직접 X]

### case03_confirmGoal
Q: 지금 가장 먼저 확인하고 싶은 것은 무엇인가요?
- prepare_materials: 방문할 때 어떤 서류나 자료를 준비해야 하는지 확인하고 싶습니다. [목표: 준비물]
- sufficient_explanation: 이미 설명한 내용으로 충분한지, 추가로 해야 할 일이 있는지 확인하고 싶습니다. [설명 함 / 목표: 충분성]
- deadline_attendance: 반드시 직접 가야 하는지, 언제까지 가야 하는지 확인하고 싶습니다. [목표: 방문 의무·기한]
- repeat_response: 이미 대응했는데, 왜 다시 요구하는지 확인하고 싶습니다. [대응 함 / 재요구 / 목표: 사유]
- unsure: 상황이 복잡해서, 무엇부터 진행해야 하는지 순서를 확인하고 싶습니다. [복합 상황 / 목표: 순서]

### case03_deadline
Q: 방문하거나 설명해야 하는 날짜는 어떻게 안내받으셨나요?
- specific_date: 안내문이나 담당자를 통해 정확한 방문 날짜나 마감일을 안내받았습니다. [날짜 확정] → 날짜 입력
- period_stated: '며칠 이내'처럼 기간만 안내받았고, 정확한 날짜는 받지 못했습니다. [기한 있음 / 기간만]
- uncertain: 날짜가 정해져 있다는 안내는 받았지만, 정확히 언제인지 확인하지 못했습니다. [기한 있음 / 날짜 미확인]
- not_stated: 날짜나 기한에 대해서는 별도의 안내를 받지 못했습니다. [기한 안내 없음]
- unsure: 안내문이 베트남어로 되어 있어, 날짜가 적혀 있는지조차 확인하지 못했습니다. [언어 장벽 / 기한 미확인]

## B. 2차 개인화

### case03_factRelationship
Q: 교통국이 확인하려는 내용은 실제 있었던 일과 비교하면 어떤가요?
- match: 교통국이 확인하려는 내용이 실제 있었던 일과 거의 같습니다. [사실 일치]
- partial: 대부분 맞지만, 날짜·장소·상황 등 일부 내용이 실제와 다릅니다. [대부분 일치 / 일부 불일치]
- mismatch: 교통국이 확인하려는 일 자체가 실제 있었던 일과 크게 다릅니다. [전체 불일치]
- hard_to_judge: 기록이 없거나 시간이 오래 지나, 실제와 비교하기 어렵습니다. [기록 X / 비교 불가]
- unknown: 교통국이 무엇을 확인하려는지 몰라, 비교할 수 없습니다. [목적 모름 / 비교 불가]

### case03_explanationDetail
Q: 교통국에 설명할 때 어떻게 진행되었나요?
- full_explanation: 당시 상황과 제가 알고 있는 사실을 직접 설명했고, 추가 질문은 받지 않았습니다. [충분 설명 / 추가 질문 없음]
- with_submitted_docs: 상황을 설명하면서, 이를 뒷받침할 서류나 자료도 함께 제출했습니다. [설명 + 서류]
- partial_explanation: 질문받은 일부 내용만 설명했고, 아직 충분히 설명하지 못했습니다. [부분 설명 / 미흡]
- agency_redemand: 설명했지만, 교통국에서 다른 내용이나 자료를 다시 요구했습니다. [설명 함 / 재요구]
- attended_insufficient: 방문은 했지만, 무엇을 설명해야 하는지 몰라 제대로 대응하지 못했습니다. [방문 함 / 준비 부족 / 대응 미흡]

### case03_authorityFollowUp
Q: 대응한 뒤, 교통국에서는 어떤 답변이 있었나요?
- no_further_action: 추가로 할 일은 없고, 절차가 그대로 진행된다는 안내를 받았습니다. [종결 방향 / 추가 요구 없음]
- more_explanation: 다시 방문하거나, 추가로 설명하라는 안내를 받았습니다. [재요구: 방문·설명]
- more_docs: 추가 서류나 자료를 제출하라는 안내를 받았습니다. [재요구: 서류]
- other_procedure: 벌금 납부나 서류 보완 등 다른 절차를 진행하라는 안내를 받았습니다. [다른 절차로 전환]
- no_response: 아직 답변을 받지 못했거나, 받은 답변의 의미를 이해하지 못했습니다. [기관 반응 불명: 무응답·이해 못함]

### case03_prepRequired
Q: 직접 방문해야 한다면, 무엇을 준비하라고 안내받으셨나요?
- documents: 관련 서류나 증빙을 준비해서 가져오라는 안내를 받았습니다. [준비물: 서류]
- explanation: 특별한 서류 없이, 당시 상황을 설명할 준비만 하면 된다고 들었습니다. [준비물: 진술]
- attendance_only: 준비물 없이, 정해진 날짜에 방문만 하면 된다고 들었습니다. [준비물 없음 / 날짜 있음] → 날짜 입력
- unknown: 방문하라는 안내만 받았고, 무엇을 준비해야 하는지는 듣지 못했습니다. [준비물 안내 없음]

### case03_prepAttendanceDate (날짜 입력, prepRequired=attendance_only)
Q: 방문하기로 한 날짜는 언제인가요?
안내(placeholder): 기억나는 날짜와 시간을 입력해 주세요.

### case03_repeatFollowUp
Q: 다시 요구받은 내용은 무엇인가요?
- more_explanation: 처음 설명한 내용이 부족하다며, 추가 설명을 요구받았습니다. [재요구: 설명 / 사유: 설명 부족]
- re_attendance: 다시 날짜를 정해서, 교통국에 직접 방문하라는 요구를 받았습니다. [재요구: 재방문]
- more_docs: 처음에는 요구하지 않았던 서류나 자료를 추가로 요구받았습니다. [재요구: 새 서류]
- multiple: 다시 방문하면서, 추가 설명과 서류까지 함께 요구받았습니다. [재요구: 복합]

### case03_blockage
Q: 현재 이 일이 진행되지 못하는 가장 큰 이유는 무엇인가요?
- what_explain: 교통국에 무엇을 어떻게 설명해야 할지 몰라, 방문 준비를 하지 못하고 있습니다. [막힘: 설명 내용 / 상태: 미착수]
- what_docs: 어떤 서류나 증빙을 가져가야 하는지 몰라, 준비가 멈춰 있습니다. [막힘: 서류 / 상태: 정지]
- why_attend: 왜 방문이나 설명을 요구하는지 이해하지 못해, 대응을 망설이고 있습니다. [막힘: 이유 / 상태: 보류]
- when_attend: 언제까지 방문하거나 제출해야 하는지 몰라, 일정을 정하지 못하고 있습니다. [막힘: 기한 / 상태: 일정 미정]
- after_explain: 이미 설명하거나 제출했지만, 다음 절차를 알 수 없어 기다리고만 있습니다. [대응 함 / 막힘: 다음 절차 / 상태: 대기]

### case03_evidence (목록형, 여러 개)
Q: 현재 보관하고 있는 자료를 모두 선택해 주세요. (여러 개 선택 가능)

- attendance_notice: 방문 날짜와 장소가 적힌 안내
- message: 교통국 담당자와 주고받은 문자·메신저·통화 기록

- none: 보관 중인 자료가 없거나, 있는지 아직 확인하지 못했습니다. [자료 없음 / 단독 선택]

### case03_finalGoal
Q: 이번 검토를 통해 이 일을 어떻게 마무리하고 싶으신가요?
- understand_demand: 교통국이 왜 요구하는지 정확히 이해하고, 그에 맞게 대응하고 싶습니다. [목표: 요구 이해]
- prepare_response: 필요한 서류와 설명을 준비해, 한 번의 방문으로 마무리하고 싶습니다. [목표: 준비 / 1회 종결]
- verify_facts: 교통국이 확인하려는 내용이 사실과 맞는지 확인하고, 다르다면 바로잡고 싶습니다. [목표: 사실 확인 / 정정 의사]
- expert: 방문이나 설명을 전문가와 함께 준비하거나, 대신 진행해 주기를 원합니다. [목표: 전문가 동행·대행]
