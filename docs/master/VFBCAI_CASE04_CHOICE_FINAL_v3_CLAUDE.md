## A. 1차 공통 (4)

### case04_supplementTarget
Q: 교통국에 서류를 제출한 뒤, 무엇을 다시 제출하라는 안내를 받았나요?
- additional_docs: 서류를 제출했지만, 처음에 제출하지 않은 서류를 추가로 제출하라는 안내를 받았습니다. [첫 제출 함 / 요구: 새 서류]
- add_content_evidence: 서류는 접수되었지만, 내용을 뒷받침할 설명이나 증빙이 부족하다는 안내를 받았습니다. [서류 접수 / 요구: 증빙 보강]
- modify_existing: 서류를 제출했지만, 작성 방법이나 형식이 맞지 않아 수정해서 다시 제출하라는 안내를 받았습니다. [요구: 수정 재제출 / 원인: 형식]
- repeat_demand: 요청받은 서류를 한 차례 다시 제출했지만, 추가 자료를 또 요청받았습니다. [재제출 1회 이상 / 추가 요구]
- unclear: 다시 제출하라는 안내는 받았지만, 무엇을 준비해야 하는지 정확히 이해하지 못했습니다. [안내 받음 / 이해 못함]

### case04_confirmGoal
Q: 지금 가장 먼저 확인하고 싶은 것은 무엇인가요?
- understand_materials: 교통국이 요구하는 서류가 정확히 무엇인지 알 수 없어, 그것부터 확인하고 싶습니다. [요구 불명확 / 목표: 요구 확인]
- understand_insufficient: 필요한 서류를 모두 제출했다고 생각하는데, 왜 부족하다고 하는지 확인하고 싶습니다. [고객 판단: 완비 / 목표: 사유]
- prepare_materials: 필요한 서류는 알고 있지만, 어디에서 어떻게 발급받아야 하는지 확인하고 싶습니다. [요구 앎 / 막힘: 발급 방법]
- repeat_reason: 이미 한 차례 다시 제출했는데, 왜 추가로 요청하는지 확인하고 싶습니다. [재제출 / 목표: 사유]
- unsure: 상황이 복잡해서, 무엇부터 진행해야 하는지 순서를 확인하고 싶습니다. [복합 상황 / 목표: 순서]

### case04_customerResponse
Q: 안내를 받은 뒤, 현재 어디까지 진행하셨나요?
- not_started: 안내만 받았고, 아직 서류 준비나 문의는 시작하지 않았습니다. [준비 X / 문의 X]
- preparing: 요청받은 서류를 준비하고 있지만, 아직 제출하지는 않았습니다. [준비 중 / 미제출]
- submitted: 요청받은 서류를 준비해 교통국에 다시 제출했습니다. [준비 완료 / 재제출 함]
- inquired: 제출하기 전에, 교통국에 전화하거나 방문해 필요한 서류를 문의했습니다. [문의 함 / 재제출 아직]
- other_method: 대행사, 회사 담당자 또는 지인에게 맡겨 그쪽에서 진행하고 있습니다. [대리 진행 / 본인 직접 X]

### case04_deadline
Q: 다시 제출해야 하는 기한은 어떻게 안내받으셨나요?
- specific_date: 안내문이나 담당자를 통해 정확한 마감일을 안내받았습니다. [기한 있음 / 날짜 확정] → 날짜 입력
- period_stated: '며칠 이내'처럼 기간만 안내받았고, 정확한 날짜는 받지 못했습니다. [기한 있음 / 기간만]
- uncertain: 기한이 있다는 안내는 받았지만, 정확히 언제까지인지 확인하지 못했습니다. [기한 있음 / 날짜 미확인]
- not_stated: 기한에 대해서는 별도의 안내를 받지 못했습니다. [기한 안내 없음]
- unsure: 안내문이 베트남어로 되어 있어, 기한이 적혀 있는지조차 확인하지 못했습니다. [안내문 있음 / 언어 장벽 / 기한 미확인]

## B. 2차 개인화

### case04_initialSubmission
Q: 처음 교통국에 서류를 제출할 때는 어떻게 준비하셨나요?
- complete: 안내받은 목록에 따라 필요한 서류를 모두 준비해 제출했습니다. [준비 기준: 목록 / 완비 제출]
- partial: 일부 서류가 준비되지 않아, 준비된 서류만 먼저 제출했습니다. [부분 제출 / 알고 제출]
- hard_to_confirm: 무엇을 제출했는지 정확히 기억나지 않고, 제출한 서류의 사본도 없습니다. [기억 X / 사본 X]

### case04_submissionRelation
Q: 이번에 요청받은 내용은 처음 제출한 서류와 비교하면 어떤가요?
- add_missing: 처음 제출한 서류는 그대로 인정되었고, 제출하지 않았던 서류를 새로 요청받았습니다. [기존 인정 / 새 서류]
- modify_content: 새로운 서류 요청은 없었고, 처음 제출한 서류 중 일부를 수정해 다시 제출하라고 했습니다. [추가 없음 / 수정]
- support_existing: 처음 제출한 서류는 맞다고 했지만, 그 내용을 뒷받침할 설명이나 증빙을 추가로 요청했습니다. [기존 인정 / 증빙 추가]
- mismatch_request: 이미 처음에 제출한 서류인데, 같은 서류를 다시 제출하라는 요청을 받았습니다. [기존 제출 사실 / 중복 요구]
- hard_to_judge: 처음에 무엇을 제출했는지 확인할 수 없어, 새로 요청한 서류인지 판단하기 어렵습니다. [기억 X / 판단 불가]

### case04_supplementReason
Q: 교통국은 다시 제출해야 하는 이유를 어떻게 설명했나요?
- missing_info: 서류나 정보 중 빠진 부분이 있다며, 해당 부분을 구체적으로 알려 주었습니다. [사유: 누락 / 설명 구체]
- incorrect_content: 기재한 내용이 틀렸거나 서류 간에 일치하지 않는다며, 수정할 부분을 알려 주었습니다. [사유: 오류 / 설명 구체]
- insufficient_proof: 기재한 내용은 맞지만, 이를 증명할 자료가 부족하다고 했습니다. [내용 인정 / 증빙 부족]
- no_reason: 이유에 대한 설명 없이, 다시 제출하라는 안내만 받았습니다. [설명 없음 / 요구만]
- unsure: 이유를 설명해 주었지만, 베트남어나 행정 용어 때문에 이해하지 못했습니다. [설명 있음 / 이해 못함 / 원인: 언어]

### case04_addDocDetail (목록형, 여러 개)
Q: 추가로 제출하라고 요청받은 서류는 어떤 종류인가요? (여러 개 선택 가능)
- id_doc: 여권·비자·임시거주 등록 같은 신분 서류
- financial_doc: 계약서·영수증·세금 납부 증명 같은 금액 서류
- certificate: 기관이나 회사에서 발급받는 증명서·확인서
- translation: 베트남어 번역본이나 공증받은 서류
- unsure: 서류 이름은 안내받았지만, 어떤 서류인지 알지 못합니다. [안내 받음 / 이해 못함]

### case04_modifyDetail (목록형, 여러 개)
Q: 수정해서 다시 제출하라고 요청받은 부분은 어디인가요? (여러 개 선택 가능)
- name_info: 이름·생년월일·여권번호 같은 인적 정보
- date_info: 날짜·기간
- amount_info: 금액·숫자
- content_info: 신청 내용이나 기재한 문장
- unsure: 수정하라는 안내는 받았지만, 어느 부분인지 알지 못합니다. [요구 받음 / 위치 모름]

### case04_evidenceDetail (목록형, 여러 개)
Q: 추가로 요청받은 설명이나 증빙은 어떤 종류인가요? (여러 개 선택 가능)
- proof_doc: 사실을 증명하는 서류(계약서·확인서 등)
- photo: 사진·이미지
- statement: 상황을 설명하는 글(설명서·경위서)
- unsure: 증빙을 추가하라는 안내만 받았고, 어떤 자료인지 알지 못합니다. [요구 받음 / 종류 모름]

### case04_unclearFocus
Q: 안내 내용을 이해하는 과정에서 어느 부분이 가장 어려웠나요?
- what_submit_list: 안내는 받았지만, 제출해야 할 서류 목록 자체를 파악하지 못했습니다. [안내 받음 / 목록 모름]
- what_submit_apply: 안내 내용은 대략 이해했지만, 제 상황에도 해당하는지 확신하지 못합니다. [내용 앎 / 본인 해당 불명]
- why_submit_reason: 제출할 서류는 알고 있지만, 왜 다시 제출해야 하는지 이해하지 못했습니다. [요구 앎 / 사유 모름]
- format_how: 제출할 서류는 알고 있지만, 어떤 양식이나 형식으로 작성해야 하는지 모릅니다. [요구 앎 / 형식 모름]
- format_where: 서류는 준비할 수 있지만, 온라인으로 제출해야 하는지 직접 방문해야 하는지 모릅니다. [준비 가능 / 제출 경로 모름]

### case04_authorityFollowUp
Q: 다시 제출하거나 문의한 뒤, 교통국에서는 어떤 답변이 있었나요?
- accepted: 서류가 접수되었고, 이제 결과를 기다리면 된다는 안내를 받았습니다. [접수 / 추가 요구 없음]
- more_supplement: 다른 서류를 추가로 제출하거나, 수정해서 다시 제출하라는 안내를 받았습니다. [재요구]
- receipt_unconfirmed: 서류를 제출했지만, 접수되었는지 확인을 받지 못했습니다. [제출 함 / 접수 미확인]
- no_response: 제출하거나 문의했지만, 아직 교통국으로부터 답변을 받지 못했습니다. [행동 함 / 무응답]
- unsure: 교통국의 답변을 받았지만, 무슨 의미인지 이해하지 못했습니다. [답변 받음 / 이해 못함]

### case04_repeatSupplement
Q: 추가로 요청받은 내용은 처음 요청과 비교하면 어떤가요?
- more_docs_new_kind: 서류를 다시 요청받았고, 처음 요청과는 다른 종류의 서류입니다. [서류 재요구 / 새 종류]
- more_docs_same_kind: 서류를 다시 요청받았고, 이미 제출한 것과 같거나 비슷한 서류입니다. [서류 재요구 / 중복]
- more_modify_reject_prior: 수정을 다시 요청받았고, 이미 수정해 제출한 부분을 또 수정하라고 했습니다. [수정 재요구 / 같은 부분]
- more_modify_new_field: 수정을 다시 요청받았고, 처음에는 언급하지 않았던 다른 부분입니다. [수정 재요구 / 새 부분]
표시 조건: supplementTarget=repeat_demand 또는 confirmGoal=repeat_reason 또는 authorityFollowUp=more_supplement (v3에서 반영됨)

### case04_blockage (3층)
Q: 현재 이 일이 진행되지 못하는 가장 큰 이유는 무엇인가요?
- what_submit: 무엇을 추가하거나 수정해야 하는지 알 수 없어, 준비를 시작하지 못하고 있습니다. [막힘: 요구 불명 / 상태: 미착수]
- why_submit: 다시 제출해야 하는 이유에 납득이 되지 않아, 그대로 준비해야 할지 망설이고 있습니다. [막힘: 사유 불신 / 상태: 보류]
- format: 필요한 서류는 알고 있지만, 발급받거나 형식에 맞게 작성하는 방법을 몰라 진행이 멈춰 있습니다. [요구 앎 / 막힘: 방법 / 상태: 정지]
- deadline: 제출 기한을 알 수 없어, 얼마나 서둘러야 할지 판단하지 못하고 있습니다. [막힘: 기한 / 상태: 판단 보류]
- after_submit: 서류는 다시 제출했지만, 다음 절차를 알 수 없어 기다리고만 있습니다. [재제출 함 / 막힘: 다음 절차 / 상태: 대기]

### case04_evidence (목록형, 여러 개)
Q: 현재 보관하고 있어 확인할 수 있는 자료를 모두 선택해 주세요. (여러 개 선택 가능)
- supplement_notice: 교통국에서 받은 안내문이나 통지서
- message: 교통국 담당자와 주고받은 문자·메신저·통화 기록
- original_submission: 처음 제출한 서류(사본이나 사진 포함)
- supplement_submission: 다시 제출한 서류(사본이나 사진 포함)
- none: 보관 중인 자료가 없거나, 있는지 아직 확인하지 못했습니다. [자료 없음/미확인] (단독 선택)

### case04_finalGoal (1차 confirmGoal과 다른 축: 마무리 방식)
Q: 이 일이 어떻게 마무리되기를 원하시나요?
- what_supplement: 필요한 서류를 정확히 확인한 뒤, 직접 준비해서 다시 제출하고 싶습니다. [목표: 요구 확정 / 방식: 본인 처리]
- why_supplement: 요청이 타당한지 확인하고, 타당하지 않다면 교통국에 설명하고 싶습니다. [목표: 정당성 확인 / 이의 의사]
- how_supplement: 준비 방법과 제출처를 안내받아, 기한 내에 제출을 마치고 싶습니다. [목표: 방법 / 기한 내 완료]
- next_step: 이미 다시 제출했으므로, 다음 절차와 결과가 나오는 시점을 확인하고 싶습니다. [재제출 함 / 목표: 결과 시점]
