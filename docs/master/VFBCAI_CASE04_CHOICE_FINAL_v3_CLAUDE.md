- 선택지 하나 = 사실 2개(2층), 꼭 필요할 때만 3개(3층). [ ] 안은 그 선택지로 얻는 사실(화면 표시 X).

## A. 1차 공통 (4)

### case04_supplementTarget
Q: 교통국에 서류를 낸 뒤, 무엇을 다시 해 오라는 안내를 받았나요?
- additional_docs: 서류를 냈지만, 처음에 내지 않은 서류를 더 가져오라는 안내를 받았습니다. [첫 제출 함 / 요구: 새 서류]
- add_content_evidence: 서류는 받아 주었지만, 내용을 뒷받침할 설명이나 증빙이 부족하다는 안내를 받았습니다. [서류 수리 / 요구: 증빙 보강]
- modify_existing: 서류를 냈지만, 작성 방법이나 형식이 틀려서 고쳐서 다시 내라는 안내를 받았습니다. [요구: 수정 재제출 / 원인: 형식]
- repeat_demand: 한 번 보완해서 다시 냈는데, 또 다른 자료를 더 요구받았습니다. [보완 2회 이상 / 추가 요구]
- unclear: 다시 해 오라는 말은 들었지만, 무엇을 해야 하는지 설명을 이해하지 못했습니다. [안내 받음 / 이해 못함]

### case04_confirmGoal
Q: 지금 가장 먼저 알고 싶은 것은 무엇인가요?
- understand_materials: 교통국이 정확히 어떤 서류를 원하는지 몰라서, 그것부터 알고 싶습니다. [요구 불명확 / 목표: 요구 확인]
- understand_insufficient: 필요한 서류를 냈다고 생각하는데, 왜 부족하다고 하는지 알고 싶습니다. [고객 판단: 완비 / 목표: 사유]
- prepare_materials: 필요한 서류는 알지만, 어디서 어떻게 받아야 하는지 알고 싶습니다. [요구 앎 / 막힘: 발급 방법]
- repeat_reason: 이미 한 번 보완했는데, 왜 또 요구하는지 알고 싶습니다. [재보완 / 목표: 사유]
- unsure: 상황이 복잡해서, 무엇부터 해야 하는지 순서를 알고 싶습니다. [복합 상황 / 목표: 순서]

### case04_customerResponse
Q: 안내를 받은 뒤, 지금까지 어디까지 해 보셨나요?
- not_started: 안내만 받았고, 아직 서류 준비나 문의를 시작하지 못했습니다. [준비 X / 문의 X]
- preparing: 요구받은 서류를 준비하기 시작했지만, 아직 다시 내지는 않았습니다. [준비 중 / 미제출]
- submitted: 요구받은 서류를 준비해서 교통국에 다시 냈습니다. [준비 완료 / 재제출 함]
- inquired: 서류를 내기 전에, 교통국에 전화하거나 찾아가서 무엇이 필요한지 물어봤습니다. [문의 함 / 재제출 아직]
- other_method: 대행사나 회사 담당자, 지인에게 맡겼고, 그쪽에서 처리하고 있습니다. [대리 진행 / 본인 직접 X]

### case04_deadline
Q: 다시 내야 하는 기한은 어떻게 안내받으셨나요?
- specific_date: 안내문이나 담당자에게서 정확한 마감 날짜를 받았습니다. [기한 있음 / 날짜 확정] → 날짜 입력(기존)
- period_stated: '며칠 안에'처럼 기간만 들었고, 정확한 날짜는 받지 못했습니다. [기한 있음 / 기간만]
- uncertain: 기한이 있다는 말은 들었지만, 언제까지인지 확인하지 못했습니다. [기한 있음 / 날짜 미확인]
- not_stated: 기한에 대해서는 아무 안내도 받지 못했습니다. [기한 안내 없음]
- unsure: 안내문이 베트남어라서 기한이 적혀 있는지조차 확인하지 못했습니다. [안내문 있음 / 언어 장벽 / 기한 미확인]

## B. 2차 개인화

### case04_initialSubmission
Q: 처음 교통국에 서류를 낼 때는 어떻게 준비하셨나요?
- complete: 안내받은 목록대로 서류를 모두 준비해서 냈습니다. [준비 기준: 목록 / 완비 제출]
- partial: 일부 서류가 준비되지 않아서, 우선 있는 서류만 먼저 냈습니다. [부분 제출 / 알고 냄]
- hard_to_confirm: 무엇을 냈는지 정확히 기억나지 않고, 낸 서류의 사본도 없습니다. [기억 X / 사본 X]

### case04_submissionRelation
Q: 이번에 요구받은 것은 처음 낸 서류와 비교하면 어떤가요?
- add_missing: 처음에 내지 않은 서류를 새로 요구받았고, 처음 낸 서류는 그대로 인정되었습니다. [새 서류 / 기존 인정]
- modify_content: 처음 낸 서류 중 일부를 고쳐서 다시 내라고 했고, 새 서류는 요구하지 않았습니다. [수정 / 추가 없음]
- support_existing: 처음 낸 서류는 맞다고 했지만, 그 내용을 뒷받침할 설명이나 증빙을 더 요구했습니다. [기존 인정 / 증빙 추가]
- mismatch_request: 이미 처음에 낸 서류인데, 같은 서류를 다시 내라는 요구를 받았습니다. [중복 요구 / 기존 제출 사실]
- hard_to_judge: 처음에 무엇을 냈는지 확인할 수 없어서, 새로 요구한 것인지 판단하기 어렵습니다. [기억 X / 판단 불가]

### case04_supplementReason
Q: 교통국은 다시 해 와야 하는 이유를 어떻게 설명했나요?
- missing_info: 서류나 정보 중 빠진 부분이 있다고, 어느 부분인지 짚어서 설명해 주었습니다. [사유: 누락 / 설명 구체]
- incorrect_content: 적은 내용이 틀렸거나 서류끼리 맞지 않는다고, 고칠 부분을 알려 주었습니다. [사유: 오류 / 설명 구체]
- insufficient_proof: 적은 내용은 맞지만, 그것을 증명할 자료가 부족하다고 했습니다. [내용 인정 / 증빙 부족]
- no_reason: 이유는 설명하지 않고, 다시 해 오라는 말만 했습니다. [설명 없음 / 요구만]
- unsure: 이유를 설명해 주었지만, 베트남어나 행정 용어라서 이해하지 못했습니다. [설명 있음 / 이해 못함 / 원인: 언어]

### case04_addDocDetail (목록형, 여러 개)
Q: 추가로 가져오라고 한 서류는 어떤 종류인가요? (여러 개 선택 가능)
- id_doc: 여권·비자·임시거주 등록 같은 신분 서류
- financial_doc: 계약서·영수증·세금 납부 증명 같은 금액 서류
- certificate: 기관이나 회사에서 발급받는 증명서·확인서
- translation: 베트남어 번역본이나 공증받은 서류
- unsure: 서류 이름은 들었지만, 무엇을 말하는지 모르겠습니다. [안내 받음 / 이해 못함]

### case04_modifyDetail (목록형, 여러 개)
Q: 고쳐서 다시 내라고 한 부분은 어디인가요? (여러 개 선택 가능)
- name_info: 이름·생년월일·여권번호 같은 인적 정보
- date_info: 날짜·기간
- amount_info: 금액·숫자
- content_info: 신청 내용이나 적어 낸 문장
- unsure: 고치라는 말은 들었지만, 어느 부분인지 모르겠습니다. [요구 받음 / 위치 모름]

### case04_evidenceDetail (목록형, 여러 개)
Q: 더 내라고 한 설명이나 증빙은 어떤 종류인가요? (여러 개 선택 가능)
- proof_doc: 사실을 증명하는 서류(계약서·확인서 등)
- photo: 사진·이미지
- statement: 상황을 설명하는 글(설명서·경위서)
- unsure: 증빙을 더 내라는 말만 들었고, 어떤 것인지 모르겠습니다. [요구 받음 / 종류 모름]

### case04_unclearFocus (6 → 5)
Q: 안내를 이해하는 과정에서 어디서 막혔나요?
- what_submit_list: 안내를 받았지만, 무엇을 내야 하는지 목록 자체를 알 수 없었습니다. [안내 받음 / 목록 모름]
- what_submit_apply: 안내 내용은 대략 알지만, 제 상황에도 해당하는지 모르겠습니다. [내용 앎 / 본인 해당 불명]
- why_submit_reason: 무엇을 내야 하는지는 알지만, 왜 다시 내야 하는지 이해하지 못했습니다. [요구 앎 / 사유 모름]
- format_how: 무엇을 낼지는 알지만, 어떤 양식이나 형식으로 만들어야 하는지 모르겠습니다. [요구 앎 / 형식 모름]
- format_where: 서류는 준비할 수 있지만, 온라인으로 내는지 직접 찾아가는지 모르겠습니다. [준비 가능 / 제출 경로 모름]

### case04_authorityFollowUp (7 → 5)
Q: 다시 내거나 문의한 뒤, 교통국에서는 어떤 반응이 있었나요?
- accepted: 교통국이 서류를 받아 주었고, 이제 결과를 기다리면 된다고 했습니다. [수리 / 추가 요구 없음]
- more_supplement: 교통국이 또 다른 서류를 더 내거나 고쳐 오라고 했습니다. [재요구]
- receipt_unconfirmed: 서류를 냈지만, 교통국이 받았는지 확인을 받지 못했습니다. [제출 함 / 수리 미확인]
- no_response: 제출하거나 문의했지만, 교통국에서 아직 아무 답이 없습니다. [행동 함 / 무응답]
- unsure: 교통국에서 답을 들었지만, 무슨 뜻인지 이해하지 못했습니다. [답변 받음 / 이해 못함]

### case04_repeatSupplement
Q: 또 요구받은 내용은 처음 요구와 비교하면 어떤가요?
- more_docs_new_kind: 다시 서류를 요구받았는데, 처음 요구와는 다른 종류의 서류입니다. [서류 재요구 / 새 종류]
- more_docs_same_kind: 다시 서류를 요구받았는데, 이미 낸 것과 같거나 비슷한 서류입니다. [서류 재요구 / 중복]
- more_modify_reject_prior: 다시 고치라고 했는데, 이미 고쳐서 낸 부분을 또 고치라고 했습니다. [수정 재요구 / 같은 부분]
- more_modify_new_field: 다시 고치라고 했는데, 처음에는 말하지 않았던 다른 부분입니다. [수정 재요구 / 새 부분]
표시 조건(수정): 재보완이 실제로 있었던 고객만 — supplementTarget=repeat_demand 또는 confirmGoal=repeat_reason 또는 authorityFollowUp=more_supplement. (현재는 2차 핵심 분기만 끝나면 모든 고객에게 표시됨 → 재보완이 없던 고객에게 "또 요구받은" 질문이 나오는 문제)

### case04_blockage (3층)
Q: 지금 이 일이 앞으로 나가지 못하는 가장 큰 이유는 무엇인가요?
- what_submit: 무엇을 더 내거나 고쳐야 하는지 몰라서, 준비를 시작하지 못하고 있습니다. [막힘: 요구 불명 / 상태: 미착수]
- why_submit: 왜 다시 내야 하는지 납득이 되지 않아서, 그대로 준비해야 할지 망설이고 있습니다. [막힘: 사유 불신 / 상태: 보류]
- format: 필요한 서류는 알지만, 발급받거나 형식에 맞게 만드는 방법을 몰라 멈춰 있습니다. [요구 앎 / 막힘: 방법 / 상태: 정지]
- deadline: 언제까지 내야 하는지 몰라서, 얼마나 서둘러야 할지 판단하지 못하고 있습니다. [막힘: 기한 / 상태: 판단 보류]
- after_submit: 서류는 다시 냈지만, 그다음 무엇을 해야 하는지 몰라 기다리고만 있습니다. [재제출 함 / 막힘: 다음 절차 / 상태: 대기]

### case04_evidence (목록형, 여러 개, 6 → 5)
Q: 지금 가지고 있어서 보여 줄 수 있는 자료를 모두 골라 주세요. (여러 개 선택 가능)
- supplement_notice: 교통국에서 받은 보완 안내문이나 통지서
- message: 교통국 담당자와 주고받은 문자·메신저·통화 기록
- original_submission: 처음 냈던 서류(사본이나 사진 포함)
- supplement_submission: 보완해서 다시 낸 서류(사본이나 사진 포함)
- none: 가지고 있는 자료가 없거나, 있는지 아직 확인하지 못했습니다. [자료 없음/미확인] (단독 선택)

### case04_finalGoal (1차 confirmGoal과 다른 축: 마무리 방식)
Q: 이 일이 어떻게 마무리되기를 원하시나요?
- what_supplement: 필요한 서류를 정확히 알고, 제가 직접 준비해서 다시 내고 싶습니다. [목표: 요구 확정 / 방식: 본인 처리]
- why_supplement: 요구가 맞는 것인지 확인하고, 맞지 않다면 교통국에 설명하고 싶습니다. [목표: 정당성 확인 / 이의 의사]
- how_supplement: 어떻게 준비하고 어디에 내야 하는지 안내받아, 기한 안에 제출을 끝내고 싶습니다. [목표: 방법 / 기한 내 완료]
- next_step: 이미 다시 냈으니, 다음 절차와 결과가 언제 나오는지 확인하고 싶습니다. [재제출 함 / 목표: 결과 시점]
